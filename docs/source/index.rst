Not Engine documentation
========================

Welcome to the Not Engine documentation. Although this documentation is a work in progress, the API specifications are ready. For practical usage examples, please refer to `our demo code <https://github.com/sinokadev/notengine/tree/main/demo>`_. If you find any errors, please report them via `GitHub Issues <https://github.com/sinokadev/notengine>`_.

.. warning::

   Not Engine is currently under development, and documentation is not a priority at this stage. Consequently, some information may be outdated or incomplete. Furthermore, as the engine is still in development, frequent breaking changes—including comprehensive overhauls of the API—may occur without prior notice. 
   
   Please also note that this engine is being developed with extensive use of LLMs. Additionally, as the developer is not a native English speaker, there may be instances of mistranslation.
