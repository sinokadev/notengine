## 배경 및 목표

현재 Not Engine에 있는 카메라는 좌표와 각도를 게임 프로그래머가 정해줘야하고, 플레이어나 특정 오브젝트를 따라가는 기능은 게임 프로그래머가 구현해야한다. 3D 게임에서 3인칭 시점은 매우 흔한 기술이지만 Not Engine에서는 그걸 게임 프로그래머가 구현해야하므로 번거롭다. 따라서 Not Engine에 유틸리티 등으로 해당 기능을 미리 구현해놓음으로서 3인칭 시점 등을 구현하기 편하게 하자.

## 설계

유틸리티 함수로 존재한다. 

`knot::utility::cameraTacking(knot::Camera cam, knot::Object obj, float distance, vec3 direction)`

- `cam`: 포인터이다. 매 루프 저 함수를 실행시키면 `cam` 객체의 좌표와 방향을 수정해준다.
- `obj`: 포인터이며, 트랙킹 할 오브젝트이다. 이 오브젝트를 향해 카메라를 비춘다.
- `distance`: 오브젝트와 카메라가 얼마나 떨어져있을지에 대한 값이다.
- `direction`: 오브젝트를 카메라가 어떤 방향에서 비추는지에 대한 값이다. 3인칭 3D 게임이라면 캐릭터는 가만히 있고 카메라만 움직이거나 하는 경우에 이 값을 수정해서 카메라를 회전 시킬수 있고, 2D 3인칭 게임이라면 (0,0,1) 같은 벡터를 집어 넣어서 Z축으로만 멀리 떨어트릴 수도 있다. 이 벡터는 단위 벡터이다. `distance`와 곱해서 사용하면 될듯하다.

카메라에는 `lookAtTarget()`이라는 함수가 있다. 이 함수는 특정 오브젝트를 바라보는 방향으로 카메라를 설정해주므로 카메라를 오브젝트를 기준으로 반지름이 `distance`인 구체 표면에 배치시키고, 이 함수를 실행하면 오브젝트를 바라보도록 설정할수 있을것이다.

구체 표면 어디에 카메라를 배치할지는 `direction`으로 결정한다.

### 의사코드 구현

```
function cameraTracking(Camera* cam, Object* obj, float distance, vec3 direction):
    // Normalize direction into a unit vector (guard against zero vector)
    if length(direction) > 0:
        unitDir = normalize(direction)
    else:
        unitDir = (0, 0, 1)

    // Calculate coordinates on a sphere of radius `distance` centered on the target
    camPos = obj.position + (unitDir * distance)

    // Move camera and orient it toward the target
    cam.setPosition(camPos)
    cam.lookAtTarget(obj)
```

```
function getDirectionFromAngles(float yaw, float pitch):
    // Clamp pitch to prevent the camera from flipping over at the poles
    pitch = clamp(pitch, -89 deg, +89 deg)

    // Convert spherical angles into a 3D unit direction vector
    direction.x = cos(pitch) * sin(yaw)
    direction.y = sin(pitch)
    direction.z = cos(pitch) * cos(yaw)

    return direction
```
